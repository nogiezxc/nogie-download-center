# NOGIE Download Center

A clean dark download-center starter built with React + Vite.

## Run locally

1. Install Node.js LTS.
2. Open a terminal in this folder.
3. Run:

```bash
npm install
npm run dev
```

Then open the local address shown by Vite.

## Build for production

```bash
npm run build
```

The production files will be in `dist/`.
